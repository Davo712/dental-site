# dental-site

Лендинг стоматологии на 3 страницы. Чистый HTML + CSS + JavaScript, **без сборки и без сервера** — достаточно открыть `index.html` двойным кликом.

## Страницы

| Файл             | Страница                                                                 |
| ---------------- | ------------------------------------------------------------------------ |
| `index.html`     | Главная: hero, цифры, услуги, преимущества, этапы, врачи, отзывы, запись |
| `services.html`  | Услуги и цены: фильтр, прайс-аккордеон, оплата и рассрочка, FAQ           |
| `contacts.html`  | О клинике: галерея, оснащение, команда, контакты, карта, запись           |
| `policy.html`    | Политика обработки персональных данных (152-ФЗ) — служебная страница      |

## Структура

```
index.html / services.html / contacts.html
assets/
  css/style.css     — вся дизайн-система (палитра, компоненты, анимации)
  js/app.js         — анимации, меню, аккордеон, слайдер, маска телефона
  img/              — сюда класть картинки и логотип
robots.txt, sitemap.xml
```

## Что заменить перед запуском

Все временные значения помечены атрибутом `data-field` или комментарием `<!-- ПЛЕЙСХОЛДЕР -->`.

### 1. Текстовые данные (поиск по `data-field`)

| Атрибут                    | Что подставить                        |
| -------------------------- | ------------------------------------- |
| `data-field="clinic-name"` | Название клиники                      |
| `data-field="phone"`       | Телефон (и `href="tel:+7..."` рядом)  |
| `data-field="email"`       | Почта (и `href="mailto:..."`)         |
| `data-field="address"`     | Адрес                                 |
| `data-field="metro"`       | Метро / ориентир                      |
| `data-field="hours"`       | Часы работы                           |
| `data-field="license"`     | Номер лицензии                        |
| `data-field="doctor-name"` | Имена врачей                          |
| `data-field="review-author"` | Имена авторов отзывов               |

### 2. Логотип

Блок `.logo` в шапке и подвале на всех трёх страницах:

```html
<span class="logo__mark">Л</span>
<!-- заменить на: -->
<img src="assets/img/logo.svg" alt="Название клиники" width="42" height="42" />
```

Также: `assets/img/favicon.svg`.

### 3. Картинки

Каждая заглушка — это `<div class="ph" data-ph="Фото · 800×550"></div>`. Нужный размер написан прямо в подписи. Меняется на:

```html
<img src="assets/img/uslugi-terapiya.jpg" alt="Лечение кариеса под микроскопом" width="800" height="550" loading="lazy" />
```

Где заглушки: hero главной, 6 карточек услуг, 6 фото в прайсе, фото врачей (4 + 4), галерея клиники (5), карта.

### 4. Карта

В `contacts.html` блок `.map` — вставить iframe Яндекс.Карт или Google Maps вместо заглушки.

### 5. Почта для заявок

После нажатия «Отправить заявку» появляется панель с выбором способа отправки. Письмо (имя, телефон, направление, комментарий, адрес страницы) уже заполнено:

- **Gmail / Яндекс Почта / Mail.ru / Outlook** — открываются в новой вкладке браузера, ничего настраивать не нужно;
- **Почтовая программа** — `mailto:`, сработает только если в системе есть почтовый клиент (Outlook, Thunderbird, «Почта» Windows). Если клиента нет, ссылка молча ничего не делает — поэтому она не основная;
- **Скопировать текст** — заявка в буфер обмена.

Адрес получателя и WhatsApp задаются **в одном месте** — начало `assets/js/app.js`:

```js
var CONTACT_EMAIL = "mail@example.ru";
var CONTACT_WHATSAPP = "";   // "79991234567" — появится кнопка «WhatsApp»
```

Отдельной форме можно задать свою почту атрибутом `data-mailto="other@example.ru"`.

> Минус любого клиентского способа: заявка уходит только если посетитель дожмёт «Отправить» в открывшемся окне. Когда появится хостинг, стоит перевести формы на серверную отправку (или сервис вроде FormSubmit / Formspree / Web3Forms) и дублировать заявку в Telegram — тогда заявка придёт по одному клику.

### 6. Политика обработки персональных данных

`policy.html` — рабочий шаблон по 152-ФЗ, не готовый юридический документ. Ссылки на него уже стоят в подвале и в чекбоксе согласия во всех формах.

Перед публикацией:

1. Заполнить реквизиты оператора: `data-field="operator-name | operator-inn | operator-ogrn | operator-address | policy-date | site-url"`.
2. Сверить перечень собираемых данных с тем, что реально работает на сайте (формы, Яндекс.Метрика, коллтрекинг).
3. Показать текст юристу — медицинская деятельность это особый случай: врачебная тайна и специальные категории данных.
4. Подать уведомление в Роскомнадзор о начале обработки персональных данных, если оно ещё не подано.

Согласие в формах — чекбокс, не отмеченный по умолчанию: без него заявка не отправляется. Это надёжнее пассивной формулировки «нажимая кнопку, вы соглашаетесь».

## Прайс-лист

Все цены на сайте взяты из документа клиники **«ПРАЙС Клиники», редакция от 03.01.2026** (утверждён приказом от 27.02.2019 № 3-9, составлен по приказу Минздрава РФ № 804н). Перенесены все 203 позиции, названия услуг сохранены как в документе.

Разделы прайса разложены по блокам сайта так:

| Раздел документа | Блок на `services.html` |
| ---------------- | ----------------------- |
| 1. Консультация-диагностика + 2. Анестезия | Консультация, диагностика и анестезия |
| 3. Профилактика и пародонтология | Профилактика и пародонтология |
| 4. Терапия | Терапия |
| 5. Эндодонтия | Эндодонтия — лечение каналов |
| 6. Хирургия | Хирургия |
| 7. Имплантация | Имплантация |
| 8. Ортопедия | Протезирование |
| 9. Ортопедия (высокоэстетическая) | Эстетическое протезирование |
| 10 + 12. Расходные материалы | Расходные материалы |
| 11. Ортодонтия | Ортодонтия |

При обновлении прайса проще всего перегенерировать блок скриптом, а не править 203 строки руками — разметка однотипная (`.acc__item` → `.price-list` → `.price-row`).

### Чего в прайсе нет — и чего поэтому нет на сайте

- **детской стоматологии** как направления (услуги по молочным зубам остались внутри терапии, эндодонтии и хирургии — они есть в прайсе);
- **седации и лечения во сне** — в прайсе только аппликационная и инъекционная анестезия;
- **лазера** — пластика уздечки идёт как обычная операция;
- **Vector-терапии** — вместо неё открытый кюретаж;
- **имплантов Straumann и Astra Tech** — в прайсе NeoBiotech, Osstem, Nobel Biocare и BICON.

### Требует подтверждения клиники

Эти формулировки остались в тексте, но документом не подтверждаются — помечены комментарием `УТОЧНИТЬ У КЛИНИКИ` или `data-field`:

- цифры в hero и блоках статистики (лет работы, число пациентов, число врачей, % возврата);
- гарантия на работы, приём с острой болью в день обращения, рассрочка и налоговый вычет;
- фразы про «60–90 минут на приём» и состав команды врачей.

## SEO — что обязательно поправить

Google находит сайт по названию бренда, когда бренд встречается единообразно в title, микроразметке и внешних источниках. Сделано на стороне кода:

- уникальные `<title>` и `description` на каждой странице (шаблон: `Название бренда — что это + город`);
- `<link rel="canonical">`, Open Graph и Twitter-карточки;
- микроразметка schema.org: `Dentist` (название, адрес, телефон, часы, услуги, соцсети), `WebSite`, `BreadcrumbList`, `FAQPage` на странице услуг;
- `robots.txt` и `sitemap.xml`;
- семантические теги, один `<h1>` на страницу, `lang="ru"`.

**Заменить перед публикацией:**

1. `https://example.ru` → реальный домен — в `canonical`, `og:url`, JSON-LD, `robots.txt`, `sitemap.xml`.
2. `НАЗВАНИЕ КЛИНИКИ` и `ГОРОД` → бренд и город — в `<title>`, `description`, `og:*`, JSON-LD.
3. В JSON-LD: телефон, адрес, индекс, координаты `latitude`/`longitude`, часы работы, ссылки `sameAs` на реальные соцсети.
4. Положить `assets/img/og-cover.jpg` (1200×630) и `assets/img/logo.png` — картинки для превью в поиске и мессенджерах.
5. Прописать `alt` у всех картинок, когда заменяете заглушки.

**Что сделать вне кода (без этого бренд не выйдет в топ по своему названию):**

- зарегистрировать карточку в Google Business Profile и Яндекс.Бизнес — с тем же названием, адресом и телефоном, что на сайте (правило NAP-консистентности);
- добавить сайт в Google Search Console и Яндекс.Вебмастер, отправить `sitemap.xml`;
- указать сайт в соцсетях и справочниках (2ГИС, ПроДокторов, Zoon) — это источники для `sameAs`;
- включить HTTPS на хостинге.

## Запуск

Просто открыть `index.html` в браузере. Плавный скролл, анимации, меню и формы работают из файла, без сервера.

Для проверки SEO-разметки лучше открыть через локальный сервер (`npx serve`), т.к. поисковые валидаторы требуют http.
