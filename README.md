# EMALIUS — сайт стоматологии

Лендинг на 3 страницы. Чистый HTML + CSS + JavaScript, **без сборки и без сервера** — достаточно открыть `index.html` двойным кликом.

## Страницы

| Файл             | Страница                                                                    |
| ---------------- | --------------------------------------------------------------------------- |
| `index.html`     | Главная: hero, цифры, услуги, преимущества, этапы, врачи, отзывы, контакты  |
| `services.html`  | Услуги и цены: фильтр, прайс из 203 позиций, оплата, FAQ                     |
| `contacts.html`  | О клинике: галерея, оснащение, команда, контакты, карта                      |

## Структура

```
index.html / services.html / contacts.html
assets/
  css/style.css     — дизайн-система: палитра, компоненты, анимации
  js/app.js         — анимации, меню, аккордеон, слайдер отзывов, табы прайса
  img/              — логотип, фавиконы, картинка для соцсетей
robots.txt, sitemap.xml
```

## Фирменный стиль

Логотип клиента (`assets/img/logo-original.png`, 1254×1254 на белом фоне) обработан в набор веб-ассетов:

| Файл | Где используется |
| ---- | ---------------- |
| `logo-mark.png` | монограмма в шапке и подвале всех страниц |
| `logo.png` | полный логотип с прозрачным фоном, для светлых подложек |
| `logo-light.png` | то же для тёмных подложек: надпись перекрашена в кремовый |
| `favicon-32.png`, `favicon-512.png`, `apple-touch-icon.png` | иконки вкладки и мобильного экрана — монограмма на кремовом фоне: на тёмном зуб внутри буквы сливался, он там негативное пространство |
| `og-cover.jpg` | превью 1200×630 для соцсетей и мессенджеров |

Белый фон вырезан не пороговым ключом, а расклейкой композита (`alpha = 1 − min(R,G,B)/255`), поэтому сглаженные края и золотой градиент остались чистыми. Если клиент пришлёт **SVG-версию логотипа** — стоит заменить: она будет резче на любых экранах.

Палитра взята из самого логотипа: чёрный `#030202`, золото `#d4b483`, крем `#fcefe0`, серо-голубой `#babdc4`. Шрифты — Cormorant Garamond (заголовки) и Manrope (текст).

## Заявки

Форм на сайте нет. Связь идёт напрямую: кнопки звонка, WhatsApp, Telegram и почта. Поэтому не нужны ни согласие на обработку персональных данных, ни политика конфиденциальности — сайт не собирает и не хранит данные посетителей.

Если позже понадобится форма записи, вернуть её можно из истории git (коммит `7b726de` — формы с валидацией, чекбоксом согласия и страницей политики).

### Чего в прайсе нет — и чего поэтому нет на сайте

- **детской стоматологии** как направления (услуги по молочным зубам остались внутри терапии, эндодонтии и хирургии — они есть в прайсе);
- **седации и лечения во сне** — в прайсе только аппликационная и инъекционная анестезия;
- **лазера** — пластика уздечки идёт как обычная операция;
- **Vector-терапии** — вместо неё открытый кюретаж;
- **имплантов Straumann и Astra Tech** — в прайсе NeoBiotech, Osstem, Nobel Biocare и BICON.

Лечение под микроскопом убрано из рекламных блоков по просьбе клиники, но строка «Исследование и лечение под микроскопом (доплата) — 3 000 ₽» осталась в прайсе: она есть в исходном документе.

## Что осталось заполнить

| Плейсхолдер | Где |
| ----------- | --- |
| `data-field="email"` | почта клиники — сейчас `mail@example.ru` |
| `data-field="hours"` | график работы — сейчас «Ежедневно 00:00 — 00:00», в микроразметке стоит 09:00–21:00 |
| `data-field="license"` | номер лицензии в подвале |
| `https://example.ru` | домен — в `canonical`, `og:url`, JSON-LD, `robots.txt`, `sitemap.xml` |
| координаты `latitude` / `longitude` | в JSON-LD, взять точные из Яндекс.Карт |
| `data-ph="Фото · …"` | 21 заглушка под фотографии, размер указан в подписи |
| ссылки `sameAs` | реальные соцсети клиники |
| Telegram-ссылки | сейчас `t.me/+79651011144`; если у клиники есть @username, лучше поставить его |
| индекс `125430` | проверить почтовый индекс |

### Требует подтверждения клиники

Помечено комментариями `УТОЧНИТЬ У КЛИНИКИ` и атрибутами `data-field="stat-*"`:

- цифры в hero и блоках статистики (лет работы, число пациентов, число врачей, % возврата);
- приём с острой болью в день обращения, налоговый вычет;
- имена и специализации врачей.

## SEO

- уникальные `<title>` и `description` на каждой странице по шаблону «Бренд — что это + город»;
- `canonical`, Open Graph, Twitter-карточки, `og-cover.jpg`;
- микроразметка schema.org: `Dentist` (адрес, телефон, часы, услуги), `WebSite`, `BreadcrumbList`, `FAQPage`;
- `robots.txt` и `sitemap.xml`;
- семантические теги, один `<h1>` на страницу, `lang="ru"`.

**Вне кода** (без этого бренд не выйдет в топ по своему названию): Google Business Profile и Яндекс.Бизнес с теми же названием, адресом и телефоном, Search Console и Вебмастер, справочники 2ГИС / ПроДокторов / Zoon, HTTPS на хостинге.

## Запуск

Открыть `index.html` в браузере. Всё работает из файла, без сервера. Для проверки SEO-разметки валидаторами нужен http — подойдёт `npx serve`.
